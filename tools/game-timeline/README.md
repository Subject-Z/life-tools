# 游戏公测时间线

垂直时间轴按日期串联游戏卡片，卡片为「Logo / 信息 / 宣传图」三栏布局。页面打开时读取同目录下的 `games.json` 并渲染。

收录范围是**尚未公测的联网游戏**：已经开启公测的条目（`betaDate` 早于当前年份）不再保留，避免时间线被历史数据占满。卡片信息只保留公测时间、运营厂商、游戏类型、游戏引擎四项，不再记录支持平台。维护时新增条目只需按下一节字段说明追加到 `games.json`。

尚未定档的游戏会归入时间线末尾的「待定」分组：日期栏显示「待定 / TBA」，公测时间字段显示 `dateNote` 的说明文案；完全没有公布过时间的游戏同样会收录，公测时间字段显示「暂未公布」。切换年份筛选时该分组自动隐藏。

卡片名称右侧直接显示官网域名作为直达链接（新窗口打开），不再占用信息栏的一行；除「今日公测」外，卡片不再显示公测状态标签。

## 打开方式

本工具需要读取 JSON，请通过本地 HTTP 服务打开（例如运行项目根目录的 `start_server.bat`，再访问 `http://127.0.0.1:8080/tools/game-timeline/`）。

直接双击 `index.html` 时浏览器会以 `file://` 协议拦截 `games.json` 的读取，页面会显示对应的错误提示。

## 数据字段

编辑 `games.json` 中 `games` 数组的条目：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 否 | 唯一标识，缺省时按顺序生成 |
| `name` | 是 | 游戏名称 |
| `nameEn` | 否 | 英文名，显示在名称右侧 |
| `betaDate` | 否 | 公测日期，`YYYY-MM-DD`，月份和日期可不补零；未公布时设为 `null` 或直接省略 |
| `dateNote` | 否 | 档期说明。未定档的游戏把 `betaDate` 设为 `null`，用此字段填写「定档 2026 年 12 月」等文案，该游戏会归入时间线末尾的「待定」分组 |
| `publisher` | 否 | 运营厂商 |
| `genre` | 否 | 游戏类型 |
| `engine` | 否 | 游戏引擎 |
| `officialUrl` | 否 | 官网链接，仅接受 http/https |
| `logo` | 否 | Logo 图片地址，支持在线 URL 或相对路径；留空时显示游戏首字占位 |
| `logoFit` | 否 | 设为 `contain` 时 Logo 等比缩放不裁切，适合横版字标；默认 `cover` |
| `cover` | 否 | 宣传图地址，支持在线 URL 或相对路径 |
| `tagline` | 否 | 一句话简介 |

`betaDate` 与 `dateNote` 都可以不填，这样的条目代表「公测时间完全未公布」，会归入「待定」分组并以「暂未公布」展示。有 `betaDate` 的游戏按日期排序进时间线，其余游戏排在时间线末尾的「待定」分组（有 `dateNote` 的排在前面），且仅在「全部」筛选下显示。时间线默认按公测时间由近到远排列，最近即将公测的排在最前；工具栏的排序按钮可切换为由远到近。`updatedAt` 用于页头显示数据更新时间（页头只展示这一项）。

## 素材来源

本项目不再内置图片文件，`logo` 与 `cover` 全部指向在线图片：

- `logo`：各游戏在 App Store 的官方应用图标（512×512，正方形）。
- `cover`：官方宣传图 / 关键视觉，取自 Steam 商店页、游戏官网或官方素材 CDN，统一缩放到 800px 宽。

替换素材时只需修改 `games.json` 中的地址：Logo 建议正方形，宣传图建议 16:9 或接近比例。图片加载失败时，卡片会自动显示文字占位，不会破坏布局。图片请求已带 `referrerpolicy="no-referrer"`，避免部分 CDN 的防盗链拦截。
