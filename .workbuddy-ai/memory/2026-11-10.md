# 2026-11-10

## 电子书阅读器：右侧面板新增「本章字数」统计

- 位置：`tools/ebook-reader/`（index.html / style.css / script.js）
- 在 `#fixedButtons` 右侧悬浮栏中、阅读进度之上插入 `#chapterWordCount` 区块（值 + 「本章字数」标签），外观沿用 `.reading-progress` 的样式语言（金色数字 + 小号单位）。
- 计数规则（`countText`）：中日韩字符（汉字/假名/注音/韩文音节，含半角假名）逐字计；其余字母文字（拉丁/希腊/西里尔）按词计，支持词内 `'`/`-`；混排时按主导语种决定单位「字 / 词」，总数 = 字数 + 词数。
- 文本来源：TXT 取 `chapter.content.join('\n')`；EPUB 取 `contentBody.innerText`（不能用 textContent，否则块级元素间无分隔，英文段落会粘连成一个词）。
- 缓存：`wordCountCache`（Map，键为章节下标），openBook / showBookshelf 时清空；章节切换先复位为「—」。
- 显示：万以上折算「万」（如 12.3万），完整数字 + 中英拆分放在 `title` tooltip。
- 已验证：多语言 TXT（中/日/韩/英/混排）与自制 EPUB 均计数正确；面板宽度 72px，长数字不溢出；返回书架会复位。
